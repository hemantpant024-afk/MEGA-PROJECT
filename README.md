# 🤖 MEGA-PROJECT - Jarvis AI Voice Assistant

A Python-based AI Voice Assistant inspired by **Jarvis** from Iron Man. It can recognize voice commands, open websites, play songs on YouTube, read the latest news, and answer questions using OpenAI.

---

## ✨ Features

- 🎤 Voice Recognition
- 🤖 Wake Word Detection ("Jarvis")
- 🌐 Open Websites
  - Google
  - YouTube
  - Facebook
  - LinkedIn
- 🎵 Play Any Song on YouTube
- 📰 Latest News Headlines
- 💬 AI Chat using OpenAI API
- 🔊 Text-to-Speech (gTTS)
- 🎧 Audio Playback using Pygame

---

## 🛠️ Technologies Used

- Python 3.x
- SpeechRecognition
- OpenAI API
- gTTS
- Pygame
- Requests
- PyWhatKit
- WebBrowser

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/hemantpant024-afk/MEGA-PROJECT.git
```

Go to the project directory:

```bash
cd MEGA-PROJECT
```

Install dependencies:

```bash
pip install speechrecognition
pip install pyttsx3
pip install requests
pip install openai
pip install gtts
pip install pygame
pip install pywhatkit
pip install pocketsphinx
```

---

## ▶️ Run the Project

```bash
python main.py
```

## 🔑 API Keys

Before running the project, replace:

```python
newsapi = "<YOUR_NEWS_API_KEY>"
```

and

```python
client = OpenAI(api_key="<YOUR_OPENAI_API_KEY>")
```

with your own API keys.
